# AmirStroy

Plumbing goods shop (Web Technologies 1, Endterm project). Pure HTML, CSS, Bootstrap 5, JavaScript and jQuery, no backend.

## Structure
- `*.html`: index, catalog, pipes, services, history, contacts (cart and order form)
- `css/style.css`: all styles
- `js/data.js`: arrays with products, services, pipe sizes and FAQ
- `js/cart.js`: cart, orders (localStorage), price format, toast message
- `js/cards.js`: creates cards with DOM methods
- `js/main.js`: shared jQuery effects (back to top, smooth scroll)
- `js/index.js`, `catalog.js`, `pipes.js`, `services.js`, `checkout.js`, `history.js`: one file per page
